## 1. 결론

- **시안 B를 '변호사 1인 브랜드형(Personal Counsel)'으로 다시 짰다.** A가 "상황별로 필요한 안내를 바로 찾는" 정보 중심이라면, B는 "김형걸 변호사 한 사람을 믿고 연락하게 만드는" 사람 중심이다.
- **jkparklaw에서는 구조를 가져왔다.** 변호사가 화면을 채우는 히어로, 소개와 주요 업무 체크리스트 옆의 영상 칼럼, '미국 이민'과 '추방재판·이민소송' 두 갈래 메뉴, 짙은 뉴스 띠, 왼쪽 큰 제목의 칼럼 아카이브, 가치 3가지, 후기 띠, 버튼 하나짜리 상담 띠, 태그와 온라인 미디어 목록이 있는 푸터다.
- **kfreemanlawoffice에서는 표현 기법을 가져왔다.** 영문 소제목, 강조어 한 단어, 짧은 막대로 된 제목 체계, 크게 쓴 전화번호, 한 칸만 강조한 수치 타일, 점선 서비스 카드, 사진 위의 간단한 문의 폼, 변호사 카드의 직통 연락처, 활성 메뉴 아래 막대다.
- **두 사이트의 약점은 버렸다.** 슬라이더, 사이트와 무관한 스톡 사진, 근거 없는 성공 건수, '전문변호사' 표현, 눌리지 않는 업무 목록, 50개짜리 태그 구름, 날짜가 오래된 콘텐츠, 영문 템플릿 문구를 쓰지 않았다.
- B의 색(크림·딥그린·테라코타)과 글꼴은 그대로 두었다. 바꾼 것은 구성과 장치다.

### 3.4 시각 체계 (측정값)

| 요소 | 값 |

| 배경 | 흰색, #F7F7F7(칼럼), #006CFF(상담 띠), #101213~#1B1D1F(뉴스·푸터) |
| 고정 요소 | 상단 헤더, 오른쪽 아래 맨 위로 버튼 |

- **얇은 큰 제목과 넓은 여백**이 특징이다. 제목 굵기 300은 국내 법률 사이트에서 드물고, 신문 칼럼 같은 인상을 준다.
- 색은 무채색에 파랑 하나뿐이다. 그래서 파란 상담 띠가 눈에 확 들어온다.

### 3.5 카피

- 히어로: "실력과 경험, 정확한 판단으로 이민자의 권리를 지킵니다" / "신분 문제를 정확하게 진단, 해결책을 찾아드립니다"
- 같은 슬로건("신분 문제를 정확하게 진단…")을 홈, 소개, 문의 페이지에서 반복한다. 한 문장이 사이트의 서명이 된다.
- 소개 페이지 첫 문장은 "저는…"으로 시작하는 1인칭이다. 이민법이 왜 어려운지부터 설명하고, 그래서 변호사가 직접 검토해야 한다고 잇는다.

### 3.6 신뢰 장치

- 변호사 프로필 14줄: 학위, 변호사협회 회원, 언론 칼럼니스트 이력, 세미나 연사, 한인 변호사협회장.
- 언론사 로고(미주중앙일보)와 상담글·칼럼 링크.
- 후기 15개: "2주만에 웨이버 승인받고 이어서 4주만에 영주권"처럼 상황, 기간, 결과가 구체적이다. 다만 날짜와 면책 문구가 없다.
- 숫자 카운터나 성공률은 쓰지 않는다.

### 3.7 전환 장치

- 영상 칼럼 바로 아래 "상담 문의 : 전화 | 이메일" 한 줄. 글을 읽던 흐름에서 바로 연락할 수 있다.
- 상담 띠의 버튼 문구에 변호사 이름이 들어간다("조나단 박 변호사 상담 문의").
- 문의 폼의 필수 항목은 이름, 이메일, 전화 3개다.
- 카카오톡과 모바일 하단 버튼은 없다.

### 3.8 변호사 소개 페이지

- 제목 띠(대법원 기둥 사진) → 2열: 왼쪽에 액자 테두리 사진, 분야, 이름 / 오른쪽에 1인칭 인사말, **파란 큰 인용문**(슬로건), 왼쪽 막대가 있는 "변호사 프로필" 소제목, 글머리 기호 14줄, 언론사 로고, 칼럼 링크.

- 제목 체계가 일정하다. **영문 소제목 → 굵은 제목(강조어 한 단어만 금색) → 46px 막대**가 모든 섹션에서 반복된다. 이 반복이 고급스러움을 만든다.

### 4.5 카피

- 서비스 약속이 "끝까지", "처음부터", "A-Z까지"처럼 범위를 말한다. 기능 나열보다 기억에 남는다.

| 첫 화면 | LA 야경 모션 + 변호사 프로필 카드 | 화면 전체 변호사 사진 + 큰 전화번호 |
| 업무분야 진입 | 상황별 카드 6개 → 분야 카드 4개 | 두 갈래(얻는 일 / 지키는 일) → 비자 번호 |
| 콘텐츠 | 소식 목록, 칼럼 카드, 세로 숏츠 | 소식 띠, 칼럼 아카이브, 가로 영상 칼럼 |
| 신뢰 장치 | 숫자 띠, 변호사 소개 + 언론 | 숫자 타일, 가치 3가지, 사례 슬라이드, 온라인 미디어 |
| 상담 | 홈 안의 긴 신청서 | 버튼 하나짜리 띠 + 4칸 폼 |
| 색 | 네이비·골드 | 크림·딥그린·테라코타 |

### 6.4 연동

- 실시간 글(Supabase)이 들어오면 B 홈의 소식 타일, 칼럼 목록, 사례 슬라이드도 같은 모양으로 바뀐다. `assets/live.js`에서 `data-variant="tiles|rows|slides"`로 구분한다.

## 7. 규정과 접근성 점검

- **수치(Rule 7.1):** 캘리포니아 변호사 광고 규정은 검증할 수 있고 오해의 소지가 없을 것을 요구한다. kfreeman의 "+2800 성공케이스" 같은 건수는 근거 자료가 필요하다. B는 20년, 글 1,500편, 카페 회원 2,100명, KBS 출연처럼 확인할 수 있는 사실만 쓰고, 사용 허락을 받는다.
- **'전문' 표현(Rule 7.4):** jkpark는 "전문변호사"라고 쓴다. 공인 전문 자격(certified specialist)을 받은 것처럼 읽힐 수 있어 B에서는 쓰지 않았다. "이민법 한 분야 20년"으로 바꿨다.
- **후기:** 지어내지 않는다. 블로그에 공개된 승인 사례만 쓰고 "과거 결과가 향후 결과를 보장하지 않는다"는 문구를 붙였다. 구글 리뷰는 연동 후 넣는다.
- **움직임:** 자동으로 넘어가는 슬라이더가 없다. 히어로 사진은 처음 한 번만 천천히 움직이고, '동작 줄이기' 설정을 켠 사용자에게는 움직이지 않는다.
- **키보드:** 드롭다운은 탭 키로 이동하면 열린다. 사례 슬라이드는 이전·다음 버튼과 가로 스크롤로 넘긴다.
- **대비:** 짙은 배경 위 글자는 흰색 또는 #EDB08F를 쓴다. 마우스를 올려야만 보이는 내용은 없다.
- **폼:** 4칸 폼에도 개인정보 수집 동의와 변호사-의뢰인 관계 고지를 넣었다(한 칸으로 합침).
