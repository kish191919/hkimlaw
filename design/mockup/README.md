# 홈페이지 디자인 시안 (반응형 HTML)

김형걸 이민법 변호사(Law Offices of Vincent Kim) 홈페이지 시안 두 가지입니다. 기획 근거는 [docs/website-plan.md](../../docs/website-plan.md), 참고 사이트 분석은 [docs/benchmark-sites.md](../../docs/benchmark-sites.md)에 있습니다.

## 보는 방법

- `index.html`을 브라우저로 열면 두 시안을 비교하는 표지가 나옵니다. 각 시안의 메인과 게시글 상세 화면으로 이동할 수 있습니다.
- 글꼴(Pretendard, Noto Serif KR)과 지도는 인터넷에서 불러옵니다. 오프라인에서는 기본 글꼴로 보입니다.
- 의뢰인에게 링크로 보내려면 이 폴더를 그대로 웹 서버에 올리면 됩니다. 모든 페이지에 `noindex`가 들어 있어 검색엔진에 노출되지 않습니다.

## 구성

```
design/mockup/
├─ index.html          표지: 두 시안 비교, 공통 기능, 확인 요청 사항
├─ a/                  시안 A · Wilshire Editorial (네이비·골드, 큰 명조 제목, LA 야경 모션)
│  ├─ index.html       메인
│  ├─ news.html        게시글 상세 (전문가 칼럼 › 실무 가이드)
│  └─ style.css
├─ b/                  시안 B · Warm Boutique (크림·딥그린·테라코타, 아치형 사진, 탭)
│  ├─ index.html
│  ├─ news.html
│  └─ style.css
└─ assets/
   ├─ base.css         공통 레이아웃·컴포넌트 (테마 변수는 각 시안 style.css에서 정의)
   ├─ mockup.js        공통 인터랙션 (외부 라이브러리 없음)
   ├─ icons.js         SVG 아이콘 (file://에서도 보이도록 스크립트로 삽입)
   ├─ attorney.jpg     변호사 사진 (임시)
   └─ attorney-face.jpg
```

## 예시·임시 내용 (의뢰인 확인 필요)

- **사진:** `assets/attorney.jpg`는 의뢰인 네이버 카페에 공개된 사무실 사진을 시안용으로 잘라 쓴 것입니다. 의뢰인에게 보내기 전에 사용해도 될지 확인하세요. 같은 파일 이름으로 바꾸면 모든 화면에 반영됩니다.
- **운영 시간, 상담료, 상담 방식, 한국어·영어 상담 표기:** 확인이 필요합니다. 화면에 "확인 필요"로 표시해 두었습니다.
- **수치(20년, 1,500+, 2,100+):** 카페·블로그 기준 값입니다. 홈페이지에 써도 되는지 확인하세요.
- **후기·숏츠:** 자리만 잡아 둔 예시입니다. 후기를 지어내지 않도록 "연동 예정" 문구로 두었습니다.
- **글 제목·날짜:** 카페·블로그의 실제 글을 바탕으로 했습니다. 요약문은 시안용으로 쓴 것입니다.
- **게시글 본문:** 상세 화면 예시(영주권 카드 분실)는 일반 정보로 썼습니다. 실제 게시 전에 변호사 검수를 받아야 합니다.

## 실제 구축(WordPress + Elementor)으로 옮길 때

- 시안의 섹션이 그대로 Elementor 템플릿 단위가 됩니다. 홈은 섹션별 컨테이너로, 게시글 상세는 Theme Builder 단일 글 템플릿으로 옮깁니다.
- 색·글꼴·둥근 정도는 `a/style.css`, `b/style.css` 맨 위 `:root` 변수에 모여 있습니다. Elementor 사이트 설정(Global Colors/Fonts)에 그대로 옮기면 됩니다.
- 비자 진단, 경로 타임라인, 스카이라인 모션은 `assets/mockup.js`의 해당 블록을 차일드 테마 스크립트로 옮기면 됩니다.
